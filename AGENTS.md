# AGENTS.md — EDA Workbench (operational rules, per Baseline Freeze v1.0)

- Python/Pydantic in `backend/` is the single source of truth for IPC contracts.
  TypeScript types in `frontend/src/shared/ipc/` are GENERATED by `tools/generate_types.py` — never hand-edit.
- Frontend talks to backend ONLY through `ipcClient` (4 bridge methods: `execute_command`,
  `execute_query`, `get_protocol_info`, `get_events`). No direct pywebview calls elsewhere.
- Job lifecycle is backend-authoritative (SYS-015; Doc05 §8.2). Frontend projects state, never owns it.
- Authorization is default-deny, fail-closed (SEC-004). Unknown commands are rejected.
- Immutable snapshots: source bytes are fingerprinted (SHA-256) and never mutated.
- No whole-DataFrame JSON over IPC; analytics payloads use Arrow IPC (M2+).
  [^1]: Arrow IPC status: **belum diterapkan** per ADR-003 (2026-11-07) — JSON + cap
  aktif (preview ≤ 200, scatter ≤ 1500, bin ≤ 30). PyArrow hanya untuk
  Parquet/CSV di dalam backend. Revisit trigger: payload agregat > 100 KB,
  scatter > 2000, atau data tabular mentah baru.
- Run gates before declaring done: `.venv/bin/python -m pytest -q` and `.venv/bin/ruff check backend tests`.
