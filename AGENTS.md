# AGENTS.md — EDA Workbench (operational rules, per Baseline Freeze v1.0)

> **Aturan keras produk (JANGAN diubah di sesi implementasi):**
> - Python/Pydantic in `backend/` is the single source of truth for IPC contracts.
>   TypeScript types in `frontend/src/shared/ipc/` are GENERATED by `tools/generate_types.py` — never hand-edit.
> - Frontend talks to backend ONLY through `ipcClient` (4 bridge methods: `execute_command`,
>   `execute_query`, `get_protocol_info`, `get_events`). No direct pywebview calls elsewhere.
> - Job lifecycle is backend-authoritative (SYS-015; Doc05 §8.2). Frontend projects state, never owns it.
> - Authorization is default-deny, fail-closed (SEC-004). Unknown commands are rejected.
> - Immutable snapshots: source bytes are fingerprinted (SHA-256) and never mutated.
> - No whole-DataFrame JSON over IPC; analytics payloads use Arrow IPC (M2+).
>   [^1]: Arrow IPC status: **belum diterapkan** per ADR-003 (2026-11-07) — JSON + cap
>   aktif (preview ≤ 200, scatter ≤ 1500, bin ≤ 30). PyArrow hanya untuk
>   Parquet/CSV di dalam backend. Revisit trigger: payload agregat > 100 KB,
>   scatter > 2000, atau data tabular mentah baru.
> - Run gates before declaring done: `.venv/bin/python -m pytest -q` and `.venv/bin/ruff check backend tests`.

## HARNESS-3 — Disiplin multi-session / multi-model / multi-harness

1. **Satu sesi = satu kartu roadmap.** Ambil kartu terkecil yang `ready` di `docs/ROADMAP-UIUX-OVERHAUL.md`, kerjakan sampai gate hijau, update `SESSION-STATE.md`, commit, baru ambil kartu berikut. Jangan melompat fase.
2. **Aturan titik bersih:** berhenti hanya pada kartu `done` dengan bukti gate; jangan tinggalkan `in_progress` tanpa commit + `SESSION-STATE.md` terisi. Bila berhenti di tengah (izin, token, crash), isi `SESSION-STATE.md` §Status sesi + commit kosong dengan pesan `wip:` — sesi berikut wajib selesai atau rollback kartu itu, bukan mengambil kartu baru.
3. **Single-writer:** hanya satu sesi mengedit `docs/SESSION-STATE.md` + `docs/ROADMAP-UIUX-OVERHAUL.md` pada satu waktu. Bila dua harness kerja paralel, pecah scope file yang disjoint (mis. `tokens.css` vs `Stepper.tsx` vs `router.tsx`); backend (`backend/`) dan frontend (`frontend/src/`) tidak pernah diubah serentak tanpa koordinasi di `SESSION-STATE.md`.
4. **Git adalah journal:** setiap selesai kartu → `git add` file yang berubah + `docs/SESSION-STATE.md` + `docs/ROADMAP-UIUX-OVERHAUL.md`, commit atomik satu kartu per commit. Jangan numpuk banyak kartu dalam satu commit.
5. **Bukti, bukan klaim:** setiap acceptance harus file:line + output command gate. Tanpa menjalankan gate, status tetap `todo`/`in_progress`, bukan `done`.

## HARNESS-4 — Aturan konten (produk, tidak boleh dilemahkan)

1. `frontend/src/shared/ipc/generated.ts` selalu generate; field/command baru: Pydantic `backend/contracts.py` dulu → `tools/generate_types.py`.
2. Frontend hanya lewat `ipcClient`. Job lifecycle backend-authoritative; progress numeric hanya bila `JobEvent.progress` nyata (0..1), bila null → indeterminate. `jobProgress()` palsu dilarang.
3. CSS shell: ` tokens.css` kini **aditif-only** sejak G6 PASS Phase 0 (`RATIF-SHELL-006` 2026-11-08). Token shell wajib `--shell-font-*`; selector fitur dilarang pakai `--shell-font-*`, selector shell dilarang pakai `--font-size-*`. Lint penjaga: `tools/token_ownership_lint.py`. `git diff frontend/src/shared/tokens.css` harus hanya tambah baris.
4. Tidak ada token warna baru di Fase 1 visual. Radius (`--radius-sm:4px` vs `DS-CORE-001:6px`) utang terbuka, tunggu amandemen — jangan diam-diam diubah.
5. Bahasa UI tunggal Bahasa Indonesia (`D-S2`). Copy shell di `frontend/src/shared/copy/shellCopy.ts`, copy fitur menang atas shell. Dilarang ID dokumen internal / `error.message` mentah di headline; branching dari `error.code` via `frontend/src/shared/copy/errorCopy.ts`.
6. Prototypes `prototypes/shell-v0/` DISPOSABLE. Bukan referensi implementasi, bukan slice G5, bukan bukti PASS. Setelah Phase 1 visual selesai, arsipkan/hapus per `prototypes/shell-v0/README.md`.
7. WCAG 2.2 AA + min window 900px BUKAN deferred. `display:none` pada region berstatus (R5/R7, nav-label) dilarang di 900px; pola wajib rail ~176px berlabel + drawer.
8. Auth sesi GitHub: `gh` terinstal (`/usr/local/bin/gh`, tidak masuk PATH agent — pakai path penuh). Push: `GH_CONFIG_DIR=<repo>/.gh-config git -c credential.helper='!/usr/local/bin/gh auth git-credential' push origin main`. Kredensial di `.gh-config/` (gitignored; jangan commit).
